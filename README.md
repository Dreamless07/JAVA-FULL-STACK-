# ☕ Java Core Concepts – Learning Repository

This repository is a collection of **Java core concept programs and practice exercises** created during hands-on training. It is organized to help reinforce OOP principles, multithreading, collections, exception handling, Java 8 features, and more.

---

## 📁 Folder & File Structure

JAVA-CORE-CONCEPTS/
│
├── Arrays/ # Programs on arrays and matrix multiplication
├── Collections/ # HashSet, List, and Collection framework practice
├── FileandExceptionHandling/ # File I/O and exception handling examples
├── Java8Features/ # Java 8 features like lambda, streams, date/time
├── multiThreading/ # Multithreading concepts and examples
├── out/production/... # Auto-generated output directory (can be ignored)
│
├── BasicAbstraction.java # Basic abstraction concept
├── PracticeAbstraction.java # Practice program using abstraction

├── publicaccessmod.java # Public access modifier example

## 🚀 Concepts Covered

| Concept                    | Description |

## 🧠 Learning Goals

- Practice the **foundations of core Java programming**
- Understand and implement **object-oriented programming**
- Use **Java 8 features** for modern, clean code
- Apply **exception handling** and **file I/O** in basic applications
- Gain exposure to **multithreaded programming**
- Learn the **Collection framework** fundamentals
